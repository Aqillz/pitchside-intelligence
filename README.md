# PitchSide Intelligence

[Open the live match lab](https://aqillz.github.io/pitchside-intelligence/) · [Methodology and event format](METHODOLOGY.md)

A browser-based football analytics dashboard for simulated matches. Compare xG, xT, shots and Zone 14 entries. The tactical pitch, threat chart, match feed, and three-part report update as the replay advances.

## Explore the dashboard

1. Choose a fictional fixture. The demo opens at the 24th event so you can explore a populated dashboard.
2. Select **Next event** or **Play replay**. Use **Restart** to return to kickoff.
3. Select an event in the match feed to highlight it. Switch between actions and density or filter the pitch, feed, and log by team.
4. Read the match report or open the methodology and import the [example JSON replay](example-events.json). Select **Play replay** after the file loads.

The score is based on goal events. xG and xT are illustrative spatial estimates. Reports are generated by rules from the events currently visible in the replay. Data stays in your tab and clears when you reload.

## Run locally

From the root of the public website checkout, run:

```shell
python -m http.server 8000 --bind 127.0.0.1
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000) in a modern browser. No API keys or package installs are required. The main branch is deployed from the root using GitHub Pages.
